# gartenbewaesserung

Bewässerungssteuerung für das Gardena smart system: Ein Raspberry Pi 3 plant und schaltet
Ventile und die Smart-Power-Steckdose (Pumpe) über die GARDENA smart system API,
eine Android-App dient als Oberfläche.

- Plan: [Erstellungsplan_Bewaesserung.md](Erstellungsplan_Bewaesserung.md)
- Regeln für die Entwicklung: [CLAUDE.md](CLAUDE.md)
- Backend: [backend/](backend/) – Tests mit `cd backend && .venv/Scripts/python -m pytest`
